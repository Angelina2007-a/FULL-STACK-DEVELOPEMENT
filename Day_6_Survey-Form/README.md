# 📋 Survey Form Website

A simple and interactive **Survey Form Website** built using **HTML, CSS, and JavaScript**.

The project collects basic user information, interests, gender, and satisfaction feedback through an attractive and responsive survey form.

## ✨ Features

- 📝 Name, Email, and Age input fields
- 👤 Gender selection using radio buttons
- ☑️ Multiple interest selection using checkboxes
- 😊 Satisfaction rating using emoji options
- 🎥 Full-screen YouTube video background
- 🎬 Slide-down animation for the Survey Form heading
- ✨ Hover and selection animations
- 📱 Responsive design
- ✅ JavaScript form validation
- 🔔 Submission confirmation message
- 🖥️ Survey responses displayed in the browser console
- 📐 Compact layout with reduced unnecessary spacing

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- YouTube Embedded Video
